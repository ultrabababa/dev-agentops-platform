实现 CLI 的进程契约

CLI 是 Runtime 的输入适配器。它不负责数据库细节，只负责把字符串解析成调用、把结果编码成 JSON，并用退出码告诉脚本成功还是失败。

学习规则：第一次让三个练习测试通过前，不打开 src/devagentops/cli.py。可以阅读你已经掌握的 storage.py，因为它是这次要调用的下层边界。

0. 先读懂函数签名

def main(argv: Sequence[str] | None = None) -> int:

先把类型注解全部拿掉，它就是 def main(argv=None):。含义是定义一个叫 main 的函数；调用者可以传入命令行参数，也可以不传。Sequence[str] | None 表示参数可以是一串字符串，也可以是空值；= None 是默认值；-> int 表示函数约定返回整数退出码。

先暂停后续实现：只有当你能用自己的话解释 argv、None 和返回的 int 各自代表什么，再进入 argparse。

1. 先画出边界

argv: list[str]
      │ argparse
      ▼
command + database: Path
      │ dispatch
      ▼
StorageStatus / StorageError
      │ JSON + exit code
      ▼
stdout + 0  /  stderr + 2

stdout 留给成功结果，stderr 留给错误；退出码让 shell、CI 和未来的 Agent Runtime 无须理解自然语言就能判断成败。
