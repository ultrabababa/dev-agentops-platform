让同一个系统通过 HTTP 报告 health/version

CLI 根据参数列表选择函数；FastAPI 根据 HTTP method 与 URL path 选择函数。两者只是输入适配器不同，返回的仍是结构化、可测试的数据。

1. 对照两种入口

CLI:  ["status", "--database", "demo.db"] → argparse → function
HTTP: GET /health                           → FastAPI  → function

GET 表示读取；/health 是 path，也叫 endpoint 或 route。FastAPI 官方把 @app.get("/health") 称为 path operation decorator：它把下面的函数登记为该请求的处理者。

2. 最小路由形状

@app.get("/health")
def health():
    return {"status": "ok"}

请求到来时 FastAPI 调用 health()，并把 Python dict 编码为 JSON response。当前函数没有等待网络或异步数据库操作，所以先使用普通 def，不引入 async。

3. 为什么先不接 SQLite

/health 只回答“HTTP 应用是否能处理请求”，/version 只暴露当前软件版本。它们不应该因为本地数据库尚未初始化就失败。数据库状态会在下一课作为独立 read endpoint 接入。
