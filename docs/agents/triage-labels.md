# Triage Labels

The engineering skills use five canonical triage roles. This repo uses the default label names.

| Skill role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate whether the issue is valid, clear, and worth actioning. |
| `needs-info` | `needs-info` | The issue is waiting on the reporter for missing information. |
| `ready-for-agent` | `ready-for-agent` | The issue is fully specified and ready for an AFK agent to implement without more human context. |
| `ready-for-human` | `ready-for-human` | The issue is understood but should be handled by a human developer. |
| `wontfix` | `wontfix` | The issue will not be actioned. |

When a skill mentions a triage role, use the corresponding GitHub label from this table.
