# Defer Full Skill Packaging in V1

V1 will implement a versioned tool registry for built-in triage tools, including tool names, descriptions, input schemas, risk metadata, and manifests, but it will not implement full skill packaging. Reusable skill packages that bundle prompts, tools, retrieval configuration, project knowledge, and operating instructions are deferred until the core ReAct runtime, trace, evaluation, tool policy, and badcase loop are stable.
