# Start with a Minimal V1 Evaluation Matrix

V1 will start with four evaluation conditions: a fixed pipeline baseline, a minimal self-built ReAct runtime, a ReAct runtime with lightweight retrieval, and a V1 candidate condition that combines ReAct, retrieval, triage tools, trace capture, and structured report submission. Multi-agent triage, MCP integration, complex sandboxing, Langfuse-backed evaluation, and framework runtimes are deferred from the initial V1 matrix so the first comparison isolates the core runtime and retrieval value before adding broader system variables.
