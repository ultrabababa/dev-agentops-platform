# Report Metric Vectors Before Composite Scores

V1 evaluation reports will present triage metrics as a metric vector rather than collapsing failure type accuracy, evidence hit rate, required fields completeness, and tool path validity into a single weighted composite score. Composite scoring is deferred until the project has enough badcase evidence to justify metric weights, because an early single score would hide trade-offs between classification accuracy, evidence quality, report completeness, and tool path behavior.
