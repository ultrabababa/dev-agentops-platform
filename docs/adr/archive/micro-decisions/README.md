# Archived Micro Decisions

This directory contains the detailed micro ADRs that were created during design grilling.

They are retained for traceability, but the active design should be read from the consolidated ADRs in `docs/adr/`:

- `0112` through `0122` summarize and supersede these micro decisions by topic.
- Do not add new micro ADRs here.
- If a future decision is small implementation detail, put it in the relevant spec, schema, checklist, or implementation notes instead of creating another ADR.
